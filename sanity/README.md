# ClinoraMedBill CMS

The production website reads published content from Sanity project `doowpoj0`, dataset `production`.

Content models cover site settings, homepage copy, services, FAQs, insights, provider audiences, specialties, nationwide state content, and legal pages. The website keeps approved local fallback content so a CMS or network interruption cannot blank the public site.

The production Studio is managed through Sanity. Ordinary content changes are published from the Studio and appear on the website at runtime; layout and application-code changes continue through GitHub.
